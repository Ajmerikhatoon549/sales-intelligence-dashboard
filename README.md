## 📌 Project Overview

Sales Intelligence Dashboard is an end-to-end Data Analytics and Data Engineering project built using Python, SQLite, Pandas, Plotly, and Streamlit.

The dashboard helps analyze sales performance through interactive visualizations, KPI tracking, revenue trends, product analysis, and regional performance insights.

---

## ✨ Features

* Interactive Region Filter
* Interactive Product Filter
* Total Revenue KPI
* Total Orders KPI
* Top Product KPI
* Average Order Value KPI
* Best Region KPI
* Revenue by Product Analysis
* Revenue by Region Analysis
* Revenue Trend Visualization
* Monthly Revenue Analysis
* Top 5 Products Dashboard
* Region Performance Ranking
* CSV Download Functionality
* SQLite Database Integration
* ETL Pipeline

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/sales-intelligence-dashboard.git
cd sales-intelligence-dashboard
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run ETL pipeline:

```bash
python etl.py
```

Run dashboard:

```bash
streamlit run app.py
```
